# v1.0.0 — Feature complete on four platforms, and the upstream questions settled

Everything this port set out to do is built and playing. What remains is
bug fixing, not construction — which is what the version number is saying.

## What 1.0 means here

- The game is **complete against the firmware it came from**: same C++ core,
  same rules, nothing stubbed out.
- It runs on **four targets** — iPhone, Apple Watch, an installable web app,
  and an Android APK.
- The **licensing and attribution questions have been asked and answered**
  by the upstream author (see *Upstream*, below), so the project's policy is
  settled rather than assumed.
- `MARKETING_VERSION` moves **0.1.0 → 1.0.0**; it had been left behind at
  the first build.

One thing 1.0 does **not** claim: **the Android APK has still never been run
on real hardware.** It compiles in CI and wraps the same web build that is
tested on iPhone, but nobody has installed it and played. Treat it as
untested until someone reports otherwise.

## Since v0.9.2

- **The documentation diagrams were redrawn.** The Mermaid blocks are gone;
  `Scripts/make_diagrams.py` now lays out all six figures by hand and emits
  English and Korean SVGs from a single layout, in the game's own palette.
  Colour carries one fixed meaning across every figure — blue is the build
  machinery, green a finished playable result, amber a result with a caveat,
  violet the `mons` files you supply, red something that cannot work, drawn
  with a no-sign. Each figure ends with a one-line conclusion, and each
  paints its own background so it reads the same in GitHub's light and dark
  themes.
- **The English install guide gained the Path A overview** the Korean guide
  already had.
- **v0.9.0, v0.9.1 and v0.9.2 were published as releases.** The notes had
  been written and committed but never tagged, so the release list stopped
  at v0.8.5.

## Where the project stands

**Platforms.** iPhone and Apple Watch (native, four install paths), an
offline-capable web app installable to the home screen, and an Android APK —
the last two built by a GitHub Actions workflow in your own fork, with no
Mac and no developer account.

**The game.** The gen-1 life cycle from the original firmware, plus the
Personality page, daily goals, the Box, the Pokédex All / Raised / Caught
filter, wild battles, the Catch / Memo / Clean / Type minigames, expeditions
and the sound-effect synthesizer from *TamaPoke — Expanded*, and dex rows
152–386 from DylanPDao's fork. 386 species.

**Languages.** Seven: Spanish, English, French, German, Italian, Portuguese
and Korean — the full UI string table, Korean species names for all 386, a
Korean-names-only mode, Korean Pokédex text, and a 두벌식 Hangul keyboard
for nicknames.

**Creature art.** None is in this repository, and none is in anything the
build produces. You supply your own `mons` folder on your own device, the
way the original reads its SD card. A CI check fails the build outright if
an asset ever appears in the output.

**How people get it.** Each person forks and hosts their own copy. Nobody
hosts a build for anyone else, and the licence keeps it that way.

## Upstream

The port's relationship to the projects it comes from was put to their
authors rather than assumed:

- **socquique** (the original firmware) confirmed that the asset handling,
  the attribution and the MIT notice all read correctly, and asked that the
  port not be listed from the firmware's README — the firmware reaches
  people who already own a specific dev board, while a phone app reaches
  everyone, and the project is deliberately kept low-profile. That request
  is respected: nothing here points at builds from upstream's repository,
  name or MakerWorld page, and the fork-your-own model stays.
- **Korean on the device firmware** turns out to be possible after all
  (`Arduino_GFX` UTF-8 output with a U8g2 CJK font), though with no
  timeline. This port's Korean data sits on upstream's own `i18n` structure,
  so it remains available if it ever becomes useful there.
- **ShadowEnemyx** and **DylanPDao** are credited in the README, NOTICE and
  LICENSE, with their MIT terms reproduced verbatim.

## Known limits

- The Android APK is untested on real hardware.
- No creature art ships; the game shows placeholders until you add your own.
- Personal use only — builds are not to be handed out or re-published,
  reskins included.

# v1.0.0 — 네 개 플랫폼에서 기능 완성, 원작 관련 문의 정리 완료

이 포트가 하려던 것은 전부 만들어졌고 실제로 돌아갑니다. 남은 일은 버그
수정이지 제작이 아니며, 버전 번호가 말하는 바가 그것입니다.

## 여기서 1.0의 의미

- 게임이 **원본 펌웨어 대비 완성**되었습니다. 같은 C++ 코어, 같은 규칙,
  비워둔 기능 없음.
- **네 개 타깃**에서 동작합니다 — 아이폰, 애플워치, 설치형 웹앱,
  안드로이드 APK.
- **라이선스와 크레딧 문제를 원작자에게 직접 묻고 답을 받았습니다**
  (아래 *원작 프로젝트* 참고). 정책이 추정이 아니라 확정된 상태입니다.
- `MARKETING_VERSION`을 **0.1.0 → 1.0.0**으로 올렸습니다. 첫 빌드 이후
  갱신되지 않고 남아 있었습니다.

1.0이 **주장하지 않는** 것 하나: **안드로이드 APK는 여전히 실제 기기에서
한 번도 실행된 적이 없습니다.** CI에서 컴파일되고 안에 든 웹 빌드는
아이폰에서 검증된 것과 같지만, 아무도 설치해서 플레이해보지 않았습니다.
보고가 들어오기 전까지는 미검증으로 취급하세요.

## v0.9.2 이후 변경

- **문서 모식도를 다시 그렸습니다.** Mermaid 블록을 걷어내고,
  `Scripts/make_diagrams.py`가 여섯 장을 직접 좌표 배치해 영문·국문 SVG를
  하나의 레이아웃에서 생성합니다. 게임 자체의 색을 쓰고, 색이 여섯 장
  전부에서 같은 의미를 나릅니다 — 파랑은 빌드 과정, 초록은 바로 플레이
  가능한 결과, 주황은 단서가 붙는 결과, 보라는 직접 준비하는 `mons`
  파일, 빨강은 불가능한 것(금지 기호). 각 그림은 결론 한 줄로 끝나고,
  배경을 직접 칠해서 GitHub 라이트/다크 어느 쪽에서도 같게 보입니다.
- **영문 설치 가이드에 경로 A 흐름도를 추가**했습니다. 국문 가이드에만
  있던 그림입니다.
- **v0.9.0 · v0.9.1 · v0.9.2를 릴리즈로 게시**했습니다. 노트는 작성되어
  커밋돼 있었지만 태그가 없어서, 릴리즈 목록이 v0.8.5에서 멈춰
  있었습니다.

## 현재 프로젝트 상태

**플랫폼.** 아이폰과 애플워치(네이티브, 설치 경로 4가지), 홈 화면에
설치되는 오프라인 웹앱, 그리고 안드로이드 APK. 뒤의 둘은 각자 자기 포크의
GitHub Actions가 빌드하며, Mac도 개발자 계정도 필요 없습니다.

**게임.** 원본 펌웨어의 1세대 생애 주기에 더해, *TamaPoke — Expanded*의
성격 페이지, 일일 목표, 보관함, 도감 전체/육성/포획 필터, 야생 배틀,
잡기·기억력·청소·타입 미니게임, 탐사, 효과음 신시사이저, 그리고
DylanPDao 포크의 도감 152–386번. 총 386종.

**언어.** 7개 — 스페인어·영어·프랑스어·독일어·이탈리아어·포르투갈어·한국어.
UI 문자열 전체, 386종 한글 이름, 한글 이름 전용 모드, 한국어 도감 설명문,
별명 입력용 두벌식 한글 키보드.

**캐릭터 그림.** 저장소에도, 빌드 산출물 어디에도 들어 있지 않습니다.
원본이 SD 카드를 읽는 것과 같은 방식으로, 각자 자기 기기에 `mons` 폴더를
넣습니다. 산출물에 에셋이 섞이면 CI가 빌드를 실패시킵니다.

**배포 방식.** 각자 포크해서 각자 호스팅합니다. 누구도 남을 위해 빌드를
호스팅하지 않으며, 라이선스가 그 상태를 유지시킵니다.

## 원작 프로젝트

이 포트가 출발한 프로젝트들과의 관계를 추정하지 않고 저자들에게 직접
물었습니다:

- **socquique**(원본 펌웨어)는 에셋 처리, 크레딧, MIT 고지가 모두 문제
  없다고 확인해 주었고, 다만 펌웨어 README에서 이 포트를 링크하지는 말아
  달라고 요청했습니다 — 펌웨어 포크는 특정 개발보드를 가진 사람에게만
  닿지만 폰 앱은 모두에게 닿고, 그 프로젝트는 의도적으로 저프로파일을
  유지하고 있기 때문입니다. 이 요청은 존중됩니다. 원작의 저장소·이름·
  MakerWorld 페이지에서 이쪽 빌드로 향하는 경로는 없으며, 각자 포크하는
  방식도 그대로 유지합니다.
- **기기 펌웨어의 한글화**는 결국 가능한 것으로 밝혀졌습니다
  (`Arduino_GFX`의 UTF-8 출력 + U8g2 CJK 폰트). 다만 일정은 없습니다.
  이 포트의 한글 데이터는 원작의 `i18n` 구조 위에 얹혀 있어서, 그쪽에서
  필요해지면 그대로 쓸 수 있습니다.
- **ShadowEnemyx**와 **DylanPDao**는 README·NOTICE·LICENSE에 명시되어
  있고, 두 사람의 MIT 조항이 원문 그대로 포함되어 있습니다.

## 알려진 한계

- 안드로이드 APK는 실기 미검증입니다.
- 캐릭터 그림은 포함되지 않습니다. 직접 넣기 전까지는 대체 그림이
  표시됩니다.
- 개인 사용 전용입니다. 리스킨을 포함해 빌드를 배포하거나 재공개하지
  마세요.
